# テニス乱数表

4〜8人、1コートのダブルス練習向けアプリです。「次の試合」を押すたびに1試合を確定し、出場・休息・ペア・対戦相手の偏りを履歴に基づいて抑えます。名前、勝敗、スコアは扱いません。

## 起動

リポジトリのルートで次を実行し、ブラウザで `http://localhost:8765/` を開きます。

```sh
python3 -m http.server 8765
```

ES Modulesを使用するため、`index.html` を `file://` で直接開く方法は想定していません。通常利用時に外部通信、サーバー側の処理、ログインは不要です。

iPhoneではHTTPSで公開したURLをSafariで開き、「共有」→「ホーム画面に追加」から起動できます。ホーム画面用アイコン、standalone表示、Safe Area、オフライン用Service Workerを含みます。

自動テストは次で実行できます。依存パッケージのインストールは不要です。

```sh
npm test
```

## 操作

- 「次の試合」で組み合わせを生成・確定します。最新試合は履歴の先頭に表示されます。
- 次の試合のプレイヤー番号を2回タップすると、その2人を入れ替えます。同じ番号をもう一度タップすると選択を解除します。
- 「前の試合を取消」で最新の1試合だけを削除します。
- 参加人数は設定から4〜8人へ変更できます。番号の大きい人から退出・再参加します。
- 強制休息は次の1試合だけに適用します。4人時は全員出場のため指定できません。5〜8人時は、出場可能者が4人未満にならない人数まで指定できます。8人時は最大4人です。
- 「新しいセッション」は確認後に履歴と統計を消去します。参加人数と個別上限は保持します。

## 人数別の動作

| 参加人数 | 出場 | 休息 | 特則 |
| ---: | ---: | ---: | --- |
| 4人 | 4人 | 0人 | 3通りのペア分けを評価し、休息プレイヤー欄は表示しません。 |
| 5〜7人 | 4人 | 1〜3人 | 出場・休息・ペア・対戦相手の偏りを評価します。 |
| 8人 | 4人 | 4人 | 最大210候補を評価し、強制休息を最大4人まで指定できます。 |

## 仕様上の判断

- 試合と人数変更を時系列イベントとして保存し、試合数・休息数・連続数・ペア回数・対戦回数を毎回再計算します。交換・取消後も統計のずれを防ぎます。
- 退出した人の連続出場・連続休息は退出時に切れます。再参加時は累計試合数、累計休息数、ペア回数、対戦回数を保持します。
- 4人時は強制休息を受け付けず、人数を4人へ変更した時点で残っている強制休息指定を解除します。最大連続出場上限を守れない場合も試合生成を止めず、制約緩和として通知します。
- 候補は4人時に3通り、8人時に最大 `C(8,4) × 3 = 210` 通りです。強制休息、上限違反、試合・休息の均等、連続休息、連続出場、ペア重複、対戦相手重複の順で辞書式に評価します。同点候補はランダムに選びます。
- 保存データはバージョン2です。既存のバージョン1保存データは、履歴・設定を保持したまま自動移行し、プレイヤー8の最大連続出場設定を未設定として追加します。破損・未知・不正な保存データは安全な初期状態へ戻します。
- 取消後、直前の試合で消費した強制休息は復元しません。取消前に行った人数変更や上限設定は残ります。
