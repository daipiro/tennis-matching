# テニス乱数表 v1

5〜7人、1コートのダブルス練習向けアプリです。「次の試合」を押すたびに1試合を確定し、履歴と統計をブラウザに保存します。名前、勝敗、スコアは扱いません。

## 起動

リポジトリのルートで `python3 -m http.server 8765` を実行し、ブラウザで `http://localhost:8765/` を開いてください。ES Modules を使用するため、`index.html` を `file://` で直接開く方法は想定していません。通常利用時に外部通信やサーバー側の処理は必要ありません。静的ホスティングにも配置できます。

iPhoneではHTTPSで公開したURLをSafariで開き、「共有」→「ホーム画面に追加」から起動できます。ホーム画面用アイコン、単独表示の設定、オフライン用Service Workerを含みます。ローカルテストの `localhost` でもService Workerを利用できます。

自動テストは `npm test` で実行できます。依存パッケージのインストールは不要です。

## 操作

- 「次の試合」でその場で確定します。最新の組み合わせは試合履歴の先頭に表示されます。
- 出場・休息プレイヤーの番号を2回タップすると、選んだ2人を交換します。もう一度同じ番号をタップすると選択を解除します。
- 「前の試合を取消」で最新の1試合だけを削除します。
- 参加人数は設定から5〜7人に変更できます。番号の大きい人から退出・再参加します。
- 強制休息は次の1試合だけに適用します。4人未満しか出場できない指定は拒否します。
- 「新しいセッション」は確認後、履歴と統計を消します。参加人数と個別上限は保持します。

## 仕様上の判断

- 試合と人数変更を時系列イベントとして保存し、試合数・休息数・連続数・ペア・対戦回数を毎回履歴から再計算します。これにより交換・取消後の統計のずれを防ぎます。試合記録には当時の連続出場スナップショットも保存します。
- 退出した人の連続出場・連続休息は退出時に切れます。再参加時は累計試合数と休息数を保持します。人数を減らした際、保留中の強制休息が4人の出場を妨げる場合は番号の大きい指定から解除します。
- 取消後、直前の試合で消費した強制休息は復元しません。取消前に行った人数変更や上限設定は残ります。
- 候補は最大105通りです。強制休息を満たす候補だけを対象にし、上限違反人数、超過量、試合数偏差、休息数偏差、連続休息、連続出場、ペア重複、対戦重複を辞書式に比較します。同点候補はランダムに選びます。個別上限は未設定または1〜10試合から選択できます。
- 保存データはバージョン1です。破損や未知バージョンは初期状態に戻し、画面に通知します。統計は保存済みのイベントから再構築します。
- PWA ファイルは相対パスで参照します。Service Workerはアプリのファイルをキャッシュし、ネットワークに接続できない時は保存済みのファイルを使います。試合データは従来どおりブラウザのlocalStorageに保存します。
